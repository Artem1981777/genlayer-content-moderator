AI content moderation on GenLayer with on-chain appeals — read a live moderation case from Testnet Bradbury. No wallet needed.

How it works. A contract stores community rules and a piece of content. On moderate(), each GenLayer validator asks an LLM to judge the content against the rules, and validators reach consensus on APPROVE / FLAG / REMOVE — recorded on-chain with a reason. Anyone can appeal() a verdict for a fresh consensus round; the appeal note is treated as an untrusted claim. This page only reads that state live.
